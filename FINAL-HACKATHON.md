# Saarthi Hackathon Final

Research has been removed from the primary product and judge UI.

The hackathon journey is now:
1. Add Data
2. See what is happening
3. Understand why
4. Decide / simulate
5. Act

The Research backend is intentionally not part of this judge-facing build, so the UI will never show OPENAI_API_KEY/research configuration errors.

The core Saarthi innovation remains:
canonical ledger → deterministic financial engine → investigation → evidence/verification → agent reasoning → Digital Twin / what-if → recommendation.
